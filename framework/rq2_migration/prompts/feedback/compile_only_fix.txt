1. Repair compilation correctness, C++ and Vulkan CTS interface usage, namespace qualification, helper usage, and template integration according to the supplied compiler evidence.

## General Output Rules
1. `template_type` must equal the `template_type` in the supplied structure re-evaluation result. Do not switch between `class` and `function`.
2. `has_params` must describe the repaired result. For a function payload, `has_check_support` and `has_init_programs` must also describe the repaired result; these two fields are not part of the class payload.
3. Return an empty string for an unused code slot and `null` where no value applies.
4. Registration remains script-owned. A class requiring constructor parameters must return structured instances through `register_cases`; each item contains only `case_name` and `params_init`.
5. Prefer one minimal `register_cases` item unless multiple cases are necessary to preserve the source test semantics.
6. `params_decl_code` and the main code slot must not both define the same parameter type. If `params_decl_code` defines `params_type`, the main code may only reference it. If the main code contains the full definition, return `params_decl_code = ""`.
7. Preserve valid Vulkan CTS type qualification, helper families, member access, and call shapes from the current candidate and surrounding CTS context. Do not turn a member object or field into a zero-argument function call.
8. Restore required qualifiers such as `tcu::`, `vk::`, `vkt::`, or `std::` when the compiler evidence or CTS context requires them.
9. When many diagnostics report undeclared identifiers, missing type specifiers, or namespace failures, repair qualification and existing helper usage before changing test structure or semantics.
10. Do not rewrite the candidate as generic Vulkan sample code or introduce shorthand CTS types unsupported by the current context.
11. Embedded shader source or other C++ string literals must remain valid C++ through a valid raw string literal or correctly escaped concatenated strings.
